В сценариях дня 5 представлены малый бизнес, инженеры, СНТ, электросетевые компании и региональные менеджеры МТС. Дополнительно проверены неизвестный срок хранения фото, монтажный вопрос, вопрос вне темы, частично подтверждённый ответ и отказ от контактов. При имитации попыток навязать ответ валидатор отклонил выдуманную цену, ценовой диапазон с выдуманной границей, несуществующий источник и ошибочный JSON. Все 57 автоматических тестов агентов прошли.

Для оценки ответов сверял четыре признака. **Верность** — факты и оговорки подтверждаются переданными разделами. **Полезность** — ответ решает вопрос в пределах доступных сведений. **Понятность** — формулировка короткая и читаемая. **Следующий шаг** — консультант предлагает конкретное действие или задаёт вопрос, который продвигает консультацию. Примеры ниже отобраны по этим признакам. Подготовленные ответы имитируют генерацию и позволяют проверять поиск, контекст и валидатор. Оценка реальной Qwen и её устойчивость к навязыванию ответа остаются открытыми. Проверка суммы в рублях охватывает числовые значения и границы диапазона. Смысл обещаний, единицы и применимость цены требуют сверки с источником.

## Передача А и воспроизведение

Существующий сборщик создал плоский ZIP, из которого корневой модуль Б импортируется в отдельном процессе и читает базу. В пересобранный ZIP попадает текущий `solution.py` с одиночным текстовым аргументом. Тесты пакетного режима останавливаются на импорте отсутствующих `data_directory` и `run_batch`. В уже сохранённом `submission.zip` используется другой вариант `solution.py`. Для сдачи А нужно сверить исходники со сборкой, прогнать пакетный режим и проверить выходной CSV. Архив локальной проверки предназначен для проверки упаковки модуля Б.

```powershell
$env:ENERGYTOOL_QA_DATA = "$env:USERPROFILE/Downloads"
python -B -X utf8 scripts/export_consultation.py --check
python -B -X utf8 -m unittest discover -s tests
python -B -X utf8 scripts/check_consultation_release.py "$env:ENERGYTOOL_QA_DATA"
```

Последняя команда использует журналы дней 2 и 3 из `qa-local` и записывает `day5_release_check.json` с фактическими ответами, использованными источниками и версиями. Журнал содержит материалы локальной проверки и хранится в каталоге, исключённом из Git.
