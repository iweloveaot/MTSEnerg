# Application Agent Contract

## Назначение

Модуль агента заявки анализирует текущий диалог с клиентом и:

1. извлекает контактные данные;
2. учитывает исправления клиента;
3. определяет недостающие поля;
4. формирует следующий вопрос;
5. формирует структурированное резюме;
6. сообщает, готова ли заявка.

Агент не отвечает за:

- хранение сессий;
- хранение заявок;
- защиту от дублей;
- вызов RAG;
- поиск по базе знаний.

Эти задачи находятся на стороне backend/orchestrator.
